# 第 03 课答案要点

代码：`steps/lesson03_main.rs`

**关键点**

1. `if` 能当值用，前提是两个分支类型一致：

```rust
let mark = if done { "✓" } else { " " };
```

注意 `{ "✓" }` 里**没有分号**。加了分号就变成"什么都不返回"，报错 `` `if` and `else` have incompatible types``。

2. `1..=3` 含 3，`1..3` 不含。写错就是经典的差一错误。

**这一课埋下的伏笔**

"最后一句不带分号 = 这一块的值"这条规则，第 04 课的函数返回值用的是同一条。Rust 里到处都是这个规则。
