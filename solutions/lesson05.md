# 第 05 课答案要点

代码：`steps/lesson05_main.rs`

**关键点**

1. `Vec<String>` = 装 String 的可变长列表。要 push 就要 `mut`。
2. 遍历**加 `&`**：`for t in &titles`。不加会把列表吃掉（第 06 课解释）。
3. `titles[99]` 越界直接崩溃，`titles.get(99)` 返回 `None`。养成用 `get` 的习惯。
4. 总数用 `.len()`，不要写死。

**下标 vs 编号**

列表下标从 0 开始，给人看的编号从 1 开始。这一课用 `i + 1` 凑合，第 07 课会给任务一个真正的 `id` 字段 —— 因为一旦能删除任务，下标和编号就对不上了。

**这一课的写法有个隐患**

两个平行的 `Vec`（`titles` 和 `flags`）长度可能不一致，编译器管不了。第 07 课用 struct 解决。
