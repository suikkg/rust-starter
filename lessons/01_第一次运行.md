# 第 01 课：第一次运行

**目标**：让程序跑起来，知道代码从哪里开始执行。

## 1. 先跑通

```bash
cd /Users/kk/rust/rust-starter
cargo run
```

看到「我的待办清单」就说明环境没问题。

再跑本课的小实验：

```bash
cargo run --example lesson01_hello
```

## 2. 要记住的四件事

| 东西 | 是什么 |
|---|---|
| `cargo` | Rust 的项目管家：编译、运行、管依赖都找它 |
| `Cargo.toml` | 项目名字、版本、用了哪些外部库 |
| `src/main.rs` | 程序入口文件 |
| `fn main()` | 程序从这里的第一行开始跑 |

两个最常用的命令：

```bash
cargo check   # 只检查能不能编译，快
cargo run     # 编译并运行
```

写代码时多用 `cargo check`，它比 `cargo run` 快很多。

## 3. 打印

```rust
println!("你好");                 // 直接打印
println!("一共 {} 课", 12);       // {} 是占位符
let n = 12;
println!("一共 {n} 课");          // 变量名可以直接写进大括号
```

`println!` 后面那个 `!` 说明它是宏，不是普通函数。现在不用深究，照着写就行。

## 5. 验收

```bash

```

- [ ] 输出里出现了你自己写的文字
- [ ] 能回答：程序是从哪一个函数开始跑的？

## 6. 常见问题

**`cargo: command not found`** —— Rust 没装好，或者终端没重开。先跑 `rustc --version` 确认。

**改了代码但输出没变** —— 确认你改的是 `src/main.rs`，而且保存了。
