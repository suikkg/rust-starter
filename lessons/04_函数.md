# 第 04 课：函数

**目标**：把重复的代码收进函数，理解参数和返回值。

## 1. 先跑实验

```bash
cargo run --example lesson04_functions
```

## 2. 写法

```rust
fn show_task(id: u32, title: &str, done: bool) {
    // 没有 -> ，说明不返回值
}

fn summary(total: u32, done: u32) -> String {
    format!("共 {total} 项，已完成 {done} 项。")   // 没有分号 = 返回它
}
```

三条规则：

1. **参数必须写类型**，Rust 不推断参数类型
2. 有返回值就要写 `-> 类型`
3. 最后一行不写分号就是返回值；写了 `return x;` 也行，但 Rust 习惯前者

## 3. `&str` 还是 `String`？

参数只读不改，就收 `&str`：

```rust
fn show(title: &str) { }     // 好：String 和 &str 都能传进来

fn show(title: String) { }   // 参数会被"吃掉"，调用方之后用不了了（第 06 课）
```

**入门期的经验法则：只读的字符串参数一律写 `&str`。**

## 4. 动手任务

改 `src/main.rs`：

3. `main` 里只剩调用，不再有 `if` 和字符串拼接

额外挑战：再写一个 `fn pending(total: u32, done: u32) -> u32` 返回未完成条数。

## 6. 常见错误

```
error[E0308]: mismatched types  expected `String`, found `()`
```
→ 函数最后一行多写了分号，等于什么都没返回。
