## 2. if

```rust
if done {
    println!("[✓]");
} else {
    println!("[ ]");
}
```

条件不用加括号，但大括号不能省。

`if` 还能当值用：

```rust
let mark = if done { "✓" } else { " " };
```

注意 `{ "✓" }` 里面**没有分号**。Rust 里最后一句不带分号就表示"这一块的值是它"。这个规则贯穿全程，函数返回值也是同一回事（第 04 课）。

### 多个分支：`else if`

```rust
let mark = if done {
    "✓"
} else if overdue {
    "!"
} else {
    " "
};
```

想写几个 `else if` 就写几个。**当值用的时候 `else` 不能省** ——
不然条件不成立时这个表达式没有值，编译器不答应。

### 条件怎么组合

| 写法 | 意思 |
|---|---|
| `a == b` / `a != b` | 等于 / 不等于 |
| `a > b` `a >= b` `a < b` `a <= b` | 比大小 |
| `a && b` | 两个都成立 |
| `a \|\| b` | 至少一个成立 |
| `!a` | 取反 |

```rust
if !done && id > 0 {
    println!("这是一条还没做的有效任务");
}
```

注意 `==` 是**两个**等号。一个等号是赋值，写错了 Rust 会直接报错
（不像有些语言会默默通过）。

## 3. 循环

### `for`：遍历一串东西

```rust
for i in 1..=3 { }   // 1、2、3
for i in 1..3  { }   // 1、2  —— 不含 3
```

`..=` 含末尾，`..` 不含。写错这个是最常见的差一错误。

下一课起你还会这样用（第 05 课细讲）：

```rust
for title in &titles {   // 挨个拿出列表里的东西
    println!("{title}");
}
```

### `while`：条件成立就一直转

```rust
let mut left = 3;
while left > 0 {
    println!("还剩 {left}");
    left -= 1;   // ← 忘了这行就是死循环
}
```

### `loop`：先转起来，自己决定什么时候停

```rust
let mut n = 0;
loop {
    n += 1;
    if n >= 3 {
        break;      // 跳出循环
    }
}
```

`loop` 就是「无条件转」，出口全靠 `break`。
什么时候用它？**退出条件在循环体中间**的时候 ——
比如「读一行、判断、不合格就再读一行」。

### `break` 和 `continue`

```rust
for i in 1..=5 {
    if i == 2 {
        continue;   // 跳过这一轮，直接进下一轮
    }
    if i == 4 {
        break;      // 整个循环到此为止
    }
    println!("{i}");   // 打印 1、3
}
```

### 死循环了怎么办

按 **Ctrl+C**。

写 `while` 忘了改条件变量（上面那个 `left -= 1`）就会转不完。
终端在刷屏就是这个，别慌，Ctrl+C 停掉，然后去找那个没变的变量。

## 4. 一个要自己想出来的模式：数数

这一课的动手任务要你打印「已完成 N 项」。N 从哪来？

```rust
let mut done_count = 0;          // 1. 先备一个计数器，注意 mut

for task_done in [true, false, true] {
    if task_done {
        done_count += 1;         // 2. 符合条件就加一
    }
}

println!("共 3 项，已完成 {done_count} 项。");   // 3. 循环结束后用它
```

三步：**循环外面定义、循环里面累加、循环外面使用**。

定义写到循环**里面**是新手最常犯的错：

```rust
for task_done in [true, false, true] {
    let mut done_count = 0;      // ❌ 每一轮都重新变回 0
    if task_done {
        done_count += 1;
    }
}
// 而且这里根本用不到 done_count —— 它出了大括号就不存在了
```

**变量活在它所在的那对大括号里，出了就没了。** 这条规则后面处处要用。

## 7. 常见错误

```
error[E0308]: `if` and `else` have incompatible types
```
→ `if` 当值用的时候，两个分支必须返回同一种类型。多半是一边带了分号一边没带。

```
error[E0317]: `if` may be missing an `else` clause
```
→ `if` 当值用却没写 `else`。条件不成立时它没有值，所以不行。

```
error[E0425]: cannot find value `done_count` in this scope
```
→ 变量定义在循环（或 `if`）的大括号里面了，出了大括号就不存在。
挪到循环外面去定义，见第 4 节。

```
error[E0384]: cannot assign twice to immutable variable
```
→ 计数器忘了写 `mut`。

**还有一个不报错的：** 程序卡住不动、或者终端一直刷屏。
那是死循环 —— `while` 的条件变量忘了改。**Ctrl+C** 停掉再去找它。
