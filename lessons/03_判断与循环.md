# 第 03 课：判断与循环

**目标**：能根据状态显示不同内容，能重复做一件事。

## 1. 先跑实验

```bash
cargo run --example lesson03_flow
```

## 2. if

```rust
if done {
    println!("[✓]");
} else {
    println!("[ ]");
}
```

条件不用加括号，但大括号不能省。

`if` 还能当值用：

```rust
let mark = if done { "✓" } else { " " };
```

注意 `{ "✓" }` 里面**没有分号**。Rust 里最后一句不带分号就表示"这一块的值是它"。这个规则贯穿全程，函数返回值也是同一回事（第 04 课）。

## 3. 循环

```rust
for i in 1..=3 { }   // 1、2、3
for i in 1..3  { }   // 1、2  —— 不含 3

let mut left = 3;
while left > 0 {
    left -= 1;
}
```

`..=` 含末尾，`..` 不含。写错这个是最常见的差一错误。

## 4. 动手任务

改 `src/main.rs`：

1. 用 `if` 决定显示 `[✓]` 还是 `[ ]`，不要再手写两行
2. 用 `for` 打印 3 条任务（暂时可以是 `第 1 条任务`、`第 2 条任务` 这样）
3. 最后打印 `共 3 项，已完成 N 项。`

## 5. 验收

```bash
cargo run
```

- [ ] 只写了一处 `[{}]`，靠 `if` 决定里面是什么
- [ ] 3 行任务是循环出来的，不是复制粘贴的
- [ ] 能解释 `1..=3` 和 `1..3` 差在哪

## 6. 常见错误

```
error[E0308]: `if` and `else` have incompatible types
```
→ `if` 当值用的时候，两个分支必须返回同一种类型。多半是一边带了分号一边没带。
