# 第 02 课：变量与可变性

**目标**：能把数据存进变量，知道什么时候要写 `mut`。

## 1. 先跑实验

```bash
cargo run --example lesson02_variables
```

## 2. 核心规则

Rust 的变量**默认不能改**：

```rust
let title = "学习 Rust";
title = "别的";        // 编译错误
```

想改必须写 `mut`：

```rust
let mut completed = 0;
completed = 1;         // 可以
completed += 1;        // 简写，等于 completed = completed + 1
```

这条规则的好处：读代码时看到没有 `mut`，就知道这个值从头到尾都一样，不用往下翻。

## 3. 会用到的类型

| 类型 | 装什么 | 例子 |
|---|---|---|
| `i32` / `u32` | 整数 / 非负整数 | `let n: i32 = -3;` |
| `f64` | 小数 | `let r: f64 = 0.5;` |
| `bool` | 真假 | `let done = true;` |
| `String` | 自己拥有的字符串 | `String::from("abc")` |
| `&str` | 借来的字符串 | `let s = "abc";` |

类型可以不写，Rust 会自己推断。写出来是为了给人看。

`String` 和 `&str` 的区别第 06 课细讲，现在只要知道：**双引号字面量是 `&str`，要存起来改动就用 `String`**。

### 两个数字上的坑，现在就得知道

**一、整数相除会把小数部分直接扔掉。**

```rust
let done = 3;
let total = 4;
println!("{}", done / total);     // 0   ← 不是 0.75
```

不是四舍五入，是**截断**。`3 / 4` 是 0，`7 / 2` 是 3。
算完成率、算百分比的时候撞上这个，结果永远是 0 或 1，而且**不会报错**。

**二、类型不会自动转，要自己写 `as`。**

```rust
let ratio = done as f64 / total as f64;    // 0.75 ✓
```

`x as f64` 读作「把 x 当成 f64 来用」。

转换的位置很要紧 —— 下面这行还是 0.0：

```rust
let ratio = (done / total) as f64;         // 先整数除得 0，再转成 0.0 ✗
```

**先转再除，不是先除再转。**

Rust 不像有些语言会帮你偷偷转类型。两个不同类型的数直接相加是编译错误：

```rust
let a: u32 = 3;
let b: f64 = 0.5;
let c = a + b;      // ❌ error[E0308]: mismatched types
let c = a as f64 + b;   // ✓
```

**这是好事**：偷偷转类型正是上面那个「完成率永远是 0」的来源，
Rust 宁可让你多写两个字，也不肯让你猜错。

## 4. 动手任务

改 `src/main.rs`，不要再把内容写死在 `println!` 里，改成用变量：

```rust
fn main() {
    let title = "学习 Rust 变量";
    let mut done = false;
    // ... 用这两个变量把那几行打印出来
}
```

要求：
1. 任务名存在变量里
2. 完成状态存在一个 `mut` 的 `bool` 变量里
3. 打印完第一遍之后，把 `done` 改成 `true`，再打印一遍

## 5. 验收

```bash
cargo run
```

- [ ] 两次打印的完成状态不一样
- [ ] 把 `mut` 删掉后 `cargo check` 报错，你能读懂那句 `cannot assign twice to immutable variable`
- [ ] 再把 `mut` 加回来，恢复正常

## 6. 常见错误

```
error[E0384]: cannot assign twice to immutable variable `done`
```
→ 变量前面漏了 `mut`。

```
error[E0308]: mismatched types  expected `String`, found `&str`
```
→ 需要 `String` 的地方给了字面量，加 `.to_string()` 或 `String::from(...)`。

```
error[E0277]: cannot add `f64` to `u32`
```
→ 两个类型不一样，Rust 不会偷偷转。给其中一个加 `as f64`。

**还有一个不报错的：** 算出来的完成率永远是 `0.0`。
那是整数除法把小数扔掉了，见第 3 节。**编译器不会提醒你这一个** ——
它是合法代码，只是不是你想要的。
