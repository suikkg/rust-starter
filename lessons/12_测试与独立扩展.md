## 2. 测试写法

```rust
#[cfg(test)]              // 只在 cargo test 时编译
mod tests {
    use super::*;

    #[test]
    fn 空列表从1开始编号() {
        assert_eq!(next_id(&[]), 1);
    }
}
```

常用断言：

```rust
assert_eq!(a, b);      // 相等，失败时会把两边的值都打出来
assert!(条件);          // 为真
assert!(result.is_err());   // 应该失败
```

失败时长这样 —— `assert_eq!` 会把两边的值都打出来：

```text
---- tests::空列表从1开始编号 stdout ----
thread 'tests::空列表从1开始编号' panicked at src/store.rs:42:9:
assertion `left == right` failed
  left: 0
 right: 1
```

**左边是你算出来的，右边是你期望的。** 顺序别写反了，写反了读起来会拧。

断言可以带一句话，失败时一起打出来：

```rust
assert!(tasks.len() == 3, "加了三条却只有 {} 条", tasks.len());
```

**报错信息里有具体数字，比只知道「断言失败了」强得多。**

跑测试：

```bash
cargo test              # 全部
cargo test next_id      # 名字里含 next_id 的
cargo test -- --nocapture   # 让测试里的 println! 也显示出来
```

`cargo test` 默认吞掉成功测试的输出，所以调试时常要加 `--nocapture`。

### 测试名用中文

```rust
#[test]
fn 空列表从1开始编号() { }
```

**Rust 允许中文函数名**，而测试名就是失败时打出来的那一行。
`空列表从1开始编号` 比 `test_next_id_empty` 直接得多 ——
你一眼就知道是哪条规则被破坏了，不用回去读代码。

（隔壁 `cpe-mini` 的 111 个测试全是中文名，理由就是这个。）

### 测试放哪

| 放哪 | 叫什么 | 能测到私有函数吗 |
|---|---|---|
| 被测代码同一个文件的 `mod tests` | 单元测试 | **能** |
| 项目根目录的 `tests/` | 集成测试 | 不能，只能用 `pub` 的 |

单元测试盯的是**单个函数**，集成测试盯的是**模块之间的接缝** ——
每个模块单独测都对、拼起来却错，这类问题只有集成测试抓得到。

这个项目的 `tests/` 目录就是给集成测试留的。

## 3. 测什么

测**边界**，不测显而易见的东西：

- 空列表
- 编号不存在
- 编号不是数字
- 存盘再读回来，数据一致（往返测试）

「显而易见的东西」是指 `add` 一条之后 `len()` 变成 1 这类 ——
它不会坏，坏了你也立刻就发现。**测试的价值在于抓那些你不会当场发现的**。

### 三个问自己的问题

1. **这个函数最容易在哪种输入上出错？** —— 那就是第一个要写的测试
2. **这条规则如果哪天被人改坏了，谁会告诉我？** —— 没人告诉你，就该写个测试
3. **这个测试失败时，它的名字说清楚了什么坏了吗？** —— 没说清楚就改名字

### 一个好用的手法：先把代码改坏

写完测试之后，**故意把被测的函数改错一行**，跑一次：

- 测试变红了 → 这个测试是有用的
- 测试还是绿的 → **这个测试什么都没保护**，重写

前面几课里那些「把它改坏，看哪个测试挂了」的任务，练的就是这个。

## 5. 任务 B：独立加一个功能（毕业考）

**没有标准答案，自己做完。**

让 `list` 支持只看未完成的：

```bash
cargo run -- list --pending
```

要求：
1. 参数解析要认 `--pending`，不给就还是显示全部
2. 不认识的选项（比如 `--pendign`）要报错提示，不能默默忽略
3. 至少为它加一个测试
4. `cargo test` 全绿

做完之后，回答这三个问题（写下来）：

- 你改了哪几个文件？为什么是这几个？
- 如果以后还要加 `--done`（只看已完成），要改的是同样这几处吗？
- 你加的测试，在哪种情况下会失败？

能答上来，就说明你不只是抄通了，而是理解了这个程序的结构。
